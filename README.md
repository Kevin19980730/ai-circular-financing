# AI circular financing

Who funds whom, and who buys from whom, in the AI build-out since January 2023.
Live page: https://kevin19980730.github.io/ai-circular-financing/

Static build of a local app, regenerated daily. Data: `data.json`, `ai_circular_deals.csv` (one row per flow), `ai_circular_financing.xlsx`. Sources are linked per deal; BIS Bulletin 137 and FT Alphaville / Sona data as credited on the page.
